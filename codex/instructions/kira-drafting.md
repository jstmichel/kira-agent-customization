# Kira Drafting Rules

- Commit messages must follow Conventional Commits.
- Commit, PR, ADR, analysis, and ticket drafts returned in chat must each be returned in a single fenced block.
- Do not return header-only drafts.
- Include concrete validation notes when the source material provides them.
- Keep wording ready to paste into the destination tool.
