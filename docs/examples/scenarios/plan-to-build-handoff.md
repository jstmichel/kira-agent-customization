# Plan To Build Handoff

Use this flow when a request is too broad to implement safely without first defining the route.

## Example

1. Start with the lead agent and ask for a route.
2. Hand off to `Plan This` for a concise implementation and verification plan.
3. Review the plan and adjust constraints if needed.
4. Use `Build This` only after the plan is accepted.
5. Validate the resulting slice before the next handoff.

## Why It Helps

- keeps planning separate from implementation
- makes approval points explicit
- reduces overlong direct-answer responses for multi-file work
